## 尾端會補上 /0

在 C 語言中，字串結尾的 \0 稱為 Null Terminator（空字元、字串終止字元），ASCII 值為 0，用來表示字串結束。

![alt text](../../images/20261011_1_c.png)

```c
#include <stdio.h>

int main()
{
    char ex[20];
    puts("Enter boyfriend's name: ");
    scanf("%19s", ex);
    printf("Dear %s.\n\n\tYou're history.\n", ex);
    return 0;
}
```

`%19s` 代表長度 19 的字串。所以就算你輸入 20 個字也只會取到第 19 個。

## \0 何時加入

建立方式 | \0 何時加入
----- | --------
char s[] = "Hello"; | 編譯時決定初始化內容
char *s = "Hello"; | 字串常值在編譯時建立，包含 \0
scanf("%19s", s); | 執行時由 scanf 寫入
strcpy(s, "Hello"); | 執行時由 strcpy 複製
char s[] = {'H','i'}; | 不會自動加入
