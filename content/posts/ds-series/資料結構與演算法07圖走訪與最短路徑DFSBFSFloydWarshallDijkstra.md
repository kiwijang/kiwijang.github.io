## 前言

圖可以有環、分支與不連通的部分。從樹走訪延伸到圖走訪時，最先需要補上的是「哪些節點已經處理過」。

## 1. DFS 與 BFS

DFS 沿著一條分支往深處走，用遞迴或 stack 保存待處理狀態。BFS 用 queue，先處理距離起點較近的層。

BFS 將節點加入佇列時就標記 visited，可以避免不同鄰居重複把同一個節點加入。DFS 也要在繼續展開前標記。

使用鄰接串列時，走訪全部節點與邊的成本為 `O(V + E)`，visited 等額外空間為 `O(V)`。鄰接矩陣逐列掃描通常為 `O(V²)`。

單一起點只能走到其可達範圍。若要走訪全圖，需要再從尚未訪問的節點啟動。實際輸出順序還會受鄰居排列影響。

## 2. 無權重圖的最短路徑

如果每條邊成本相同，BFS 第一次到達某節點時，就得到最少邊數的路徑。保存 parent 可以重建路線。

若邊權重不同，最少邊數不一定代表最低總成本，這時要使用加權最短路徑方法。

## 3. Floyd–Warshall

Floyd–Warshall 求所有節點配對的最短距離。先將自身距離設為 0，有邊的位置填入權重，其餘設為無限大。

核心更新：

```text
for k = 0 .. V-1:
  for i = 0 .. V-1:
    for j = 0 .. V-1:
      dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
```

k 必須放在最外層，代表逐步允許哪些中繼節點。時間為 `O(V³)`，距離表空間為 `O(V²)`。

可以處理負權邊，但若存在影響路徑的負環，相關最短距離就沒有有限最小值。完成後 `dist[i][i] < 0` 可用來檢查負環。

## 4. Dijkstra

Dijkstra 從單一起點開始，每次取出尚未確定、暫定距離最小的節點，再對鄰居做 relaxation：

`dist[v] = min(dist[v], dist[u] + weight(u, v))`

它比較的是從起點累積的距離，並不是只挑眼前最便宜的邊。標準版本要求邊權重非負。

以鄰接串列加二元 Min Heap 實作，常見時間為 `O((V + E) log V)`；直接線性挑最小值的版本可為 `O(V²)`。堆積中若保留重複候選，取出時要略過過期距離。

## 5. 方法比較與心得

| 問題 | 方法 |
| --- | --- |
| 可達性、完整走訪 | DFS 或 BFS |
| 同成本邊的單源最短路徑 | BFS |
| 非負權重的單源最短路徑 | Dijkstra |
| 所有配對最短路徑 | Floyd–Warshall，另檢查負環 |

我的理解方式是先確認「起點有幾個、邊是否有權重、能否出現負值」，再選演算法。

最短路徑如果只保存距離，還無法告訴使用者怎麼走。實作需求通常也需要前驅或下一跳資訊，才能把計算結果轉成可閱讀的路線。
