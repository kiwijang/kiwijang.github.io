## 前言

圖片可以展平成向量，為什麼還需要 CNN？這篇先看局部運算與權重共享，再看看同樣的特徵擷取方式怎麼用到分類、偵測與分割。

## 1. CNN 把影像結構放進模型

全連接層把每個輸入連到每個輸出，參數可能很多。CNN 則用 kernel 處理局部區域，同一組權重在不同位置重複使用。

這是 inductive bias (歸納偏置): 架構先假設附近像素有關聯、局部模式可以在不同位置出現。實際的邊緣與紋理特徵，仍需要從資料學習。

> 小補充: 卷積常具有平移等變性，不等於整個 CNN 天生對任何位移、縮放都完全不變。Padding、stride、pooling 與任務也會影響結果。

## 2. Kernel、channel 與 feature map

Kernel 在輸入上滑動，每個位置計算加權和，再搭配 activation。輸出是 feature map。

RGB 輸入有 3 個 channels，一個標準卷積 filter 的權重會涵蓋全部輸入 channels。64 個 filters 就產生 64 個輸出 channels。

深度學習套件裡常稱的 convolution，通常實作不翻轉 kernel 的 cross-correlation；不影響理解可學習局部加權和的核心。

## 3. 輸出尺寸怎麼算？

以下針對單一空間維度、兩側相同 padding 的情況:

```text
K_effective = D(K − 1) + 1
W_out = floor((W_in + 2P − K_effective) / S) + 1
```

K 是 kernel size、D 是 dilation、P 是單側 padding、S 是 stride。Height 也可以用同樣方式計算。

例如 W=5、K=3、D=2、P=1、S=1，有效 kernel 為 5，輸出為 3。若使用框架的 `padding="same"`，則要依其自動 padding 規則判斷；輸出通常為 `ceil(W/S)`。

Pooling 也需要注意 stride。2×2 max pooling 若 stride=2，通常把尺寸減半；stride=1 則是重疊窗口，不是同樣結果。

## 4. 參數量的比較

一般 `groups=1`、每個 filter 有 bias 的 Conv2D，參數數量為:

```text
(K_h × K_w × C_in + 1) × C_out
```

對 224×224×3 圖片:

| 第一層設定 | 參數數量 |
| --- | --- |
| Flatten 後接 Dense(1000) | `(150528+1)×1000 = 150529000` |
| 3×3 Conv2D，64 filters | `(3×3×3+1)×64 = 1792` |

這個比較展示局部連接與共享的成本差異，兩層輸出的 shape 與功能並不相同，不代表只換一層就能得到相同模型效果。

## 5. 經典 CNN 與建模方式

簡報介紹 LeNet、AlexNet 與 VGG。VGG 反覆堆疊小型 3×3 卷積與 pooling；多個小 kernel 可以擴大有效感受野，但中間還有非線性，所以不等同一個大型線性卷積。

簡單線性堆疊可以用 Sequential；多輸入、分支、skip connections 則適合 Functional API。下面是補充的小模型:

```python
from tensorflow import keras

inputs = keras.Input(shape=(32, 32, 3))
x = keras.layers.Conv2D(32, 3, padding="same", activation="relu")(inputs)
x = keras.layers.MaxPooling2D(2)(x)
x = keras.layers.Conv2D(64, 3, padding="same", activation="relu")(x)
x = keras.layers.GlobalAveragePooling2D()(x)
outputs = keras.layers.Dense(10, activation="softmax")(x)
model = keras.Model(inputs, outputs)
model.summary()
```

Global average pooling 對每個 channel 的空間位置取平均，再接分類層；這裡是模型結構示例，未宣稱特定 accuracy。卷積參數定義見 [Keras Conv2D](https://keras.io/api/layers/convolution_layers/convolution2d/)。

## 6. 遷移學習不用全部從零開始

先使用預訓練模型當特徵擷取器，替換任務輸出層並凍結 backbone；新 head 訓練穩定後，再視需要解凍部分層，以較小 learning rate 微調。

注意圖片前處理要符合預訓練模型。改變 `trainable` 後，Keras 通常需要重新 compile；BN 的訓練／推論行為也要另外留意，參考 [Transfer learning 指南](https://keras.io/guides/transfer_learning/)。

簡報中的 CIFAR-10 與貓狗比較是課程實驗，不是 CNN、regularization 或 transfer learning 必定達到的準確率。

## 7. 分類、偵測與分割

| 任務 | 輸出 |
| --- | --- |
| Image classification | 整張圖片的類別 |
| Object detection | 物件類別與 bounding boxes |
| Semantic segmentation | 每個像素的類別 |
| Instance segmentation | 區分同類別的不同物件 |
| Panoptic segmentation | 結合像素類別與物件實例 |

簡報用 YOLOv3 說明網格與 anchors，再以 NMS 減少高度重疊的候選框。這是版本特定的概念，不要直接套用到所有 YOLO 變體。

## 8. U-Net 的 encoder、decoder 與 skip connections

Encoder 逐步壓縮空間尺寸並學特徵，decoder 逐步恢復解析度，產生像素級輸出。跨層 skip connection 把較早的細節送到 decoder。

原始 U-Net 會串接對應 encoder feature maps，不是 ResNet 的 elementwise addition。Up-sampling 與 transposed convolution 也不是同一個運算；前者放大尺寸，後者有可學習權重。架構可參考 [U-Net 原始論文](https://arxiv.org/abs/1505.04597)。
