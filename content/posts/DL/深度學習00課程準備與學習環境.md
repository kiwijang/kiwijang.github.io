## 前言

開始學深度學習前，除了會寫 Python，還需要準備什麼？這篇先整理課程路線與環境，後面看到 tensor、loss 和 gradient 時，就比較知道它們在做什麼。

> 本篇依 Chapter 0 課程準備簡報整理。工具資訊於 2026-10-14 查核；硬體價格、雲端配額與訓練時間不當成固定規格。

## 1. 這個系列會學什麼？

課程從人工神經網路開始，再介紹反向傳播、模型訓練、CNN 和 ResNet。後半段則延伸到 NLP、生成模型與強化學習。

這些主題看起來很多，但可以先抓住一條主線:

```text
資料的數值表示 → 模型計算 → 損失 → 求梯度 → 更新參數 → 評估
```

不同模型會改變資料表示和架構，但前面的基本訓練觀念可以一路用下去。

## 2. Python 與機器學習先備知識

Python 至少要熟悉變數、list／dict、迴圈、函式、模組、class 和檔案讀取。看得懂範例之後，也要試著不看影片自己重寫，確認理解資料怎麼流動。

| 工具／觀念 | 在課程中的用途 |
| --- | --- |
| NumPy | 陣列、矩陣與數值運算 |
| Pandas | 整理表格資料 |
| Matplotlib／Seaborn | 查看資料分布與訓練曲線 |
| scikit-learn | 資料切分、基準模型與評估 |
| Train／validation／test | 分開學習、調參與最終評估 |
| Overfitting／underfitting | 判斷模型是否學到可泛化的規律 |

不要把驗證集和測試集當成同一件事。調整模型時看 validation，最後再用 test 評估，避免一直看測試結果，把測試集也間接拿來調參。

## 3. 數學不一定一次全部學完

- 線性代數: tensor shape、矩陣乘法與向量表示。
- 微積分: 導數、偏導數與 chain rule。
- 機率統計: 分布、抽樣、期望值與損失函數。
- 演算法: 理解計算成本、記憶體與重複運算。

例如反向傳播會用 chain rule，VAE 會用機率分布。先知道概念在哪裡用，再回頭補相關數學，會比硬背全部公式更有方向。

## 4. AI、ML 與 DL 的關係

人工智慧 (AI) 是較大的範圍；機器學習 (ML) 是其中透過資料學習規律的方法；深度學習 (DL) 則使用多層神經網路學習表示。

簡報用感知器、反向傳播、CNN、Transformer 串起發展脈絡。這裡先記得: **模型、資料與算力要一起配合**。架構在數學上能表示某個函數，不代表手上的資料與硬體就能把它訓練好。

## 5. Colab、GPU 與實驗環境

Colab 是瀏覽器中的 notebook 環境，適合課程實驗。執行程式的地方是遠端 runtime，不是自己的瀏覽器。

Colab 有免費計算資源，也可能提供 GPU／TPU，但資源不保證可用。簡報中的「固定 T4、12 小時、90 分鐘閒置」不能當成永久限制；實際配額、硬體與 session 行為會變動，見 [Colab 官方 FAQ](https://research.google.com/colaboratory/faq.html)。

GPU 適合大量平行張量運算，但不代表每段 Python 都會自動加速。資料讀取、前處理與小型工作也可能受 CPU 或 I/O 限制。

在 notebook 中可先確認:

```python
import tensorflow as tf

print("TensorFlow:", tf.__version__)
print("GPUs:", tf.config.list_physical_devices("GPU"))
```

這段只檢查環境，不代表模型已使用到 GPU。訓練前也要注意 batch size 與可用記憶體。

## 6. 怎麼記錄實驗比較有用？

每次實驗留下資料版本、切分方式、模型設定、learning rate、batch size、套件版本與結果。隨機種子也值得記錄，但單一 seed 不等於所有硬體都能產生完全相同結果。

遇到錯誤時，先看完整訊息與 tensor shape，再做最小範例。筆記可以寫「輸入是什麼、預期什麼、實際發生什麼」，比只存一張報錯截圖更容易回頭理解。
